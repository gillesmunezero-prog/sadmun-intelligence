# Registre Entreprises Internationales -- Phase 1 (Europe)

Ce registre constitue la premiere base de prospection commerciale de SADMUN Intelligence.
Objectif : repondre a la question "si Gilles veut prospecter demain matin, quelles sont
les premieres entreprises europeennes a regarder ?"

## Methodologie de scoring (0-100)
Score = 30 (base) + Secteur (15 si secteur strategique prioritaire : eau, routes, energie,
resilience climatique, transport ; 10 si BTP/ingenierie generale) + Presence Afrique
(15 Oui / 5 A qualifier / 0 Non) + Presence Afrique australe (15 Oui / 5 A qualifier /
0 Non) + Presence Mozambique (25 Confirmee / 12 Probable / 0 A qualifier) + Envergure
internationale reconnue (5 si groupe majeur, 0 sinon). Score plafonne a 97.

## Regle de confiance -- a lire avant toute utilisation commerciale
Les champs "Presence Afrique" et "Presence Afrique australe" reposent sur la connaissance
publique generale du positionnement international de ces groupes (communication
institutionnelle, notoriete sectorielle). Ils doivent etre verifies avant tout usage
commercial engageant. Les champs "Presence Mozambique" restent "A qualifier" tant qu'aucune
source publique precise n'a ete verifiee dans cette session, sauf mention explicite d'une
source (World Bank Procurement, disclosure officielle, presse specialisee citee). Aucun nom
de decideur n'est jamais invente : toutes les fonctions listees sont a rechercher.
